# 🐾 PetCare – Smart Veterinary Clinic & Pet Health Management System

## 📖 Overview

PetCare is a Smart Veterinary Clinic & Pet Health Management System developed using Data Structures and Algorithms (DSA). This project demonstrates the implementation of AVL Trees, Graph Traversal Algorithms (BFS & DFS), and Prim's Minimum Spanning Tree (MST) for efficient pet healthcare management and clinic network optimization.

The project is divided into three case studies:

- CO1 – AVL Tree Implementation
- CO2 – Graph Traversal using BFS & DFS
- CO3 – BFS, DFS and Prim's Minimum Spanning Tree

---

# 📌 CO1 – AVL Tree Implementation

## Objective

To develop an efficient PetCare Management System using AVL Tree data structure for storing and managing pet records while maintaining balanced search operations.

## Features

- Add Pet Records
- Search Pet Information
- Update Pet Details
- Delete Pet Records
- Display Pet Records
- Automatic Tree Balancing

## Data Structure Used

- AVL Tree

## Algorithms Used

- AVL Tree Insertion
- AVL Tree Deletion
- AVL Tree Search
- LL Rotation
- RR Rotation
- LR Rotation
- RL Rotation

## Applications

- Veterinary Clinics
- Pet Hospitals
- Animal Care Centers
- Pet Adoption Management Systems

## Outcome

The AVL Tree ensures efficient searching, insertion, and deletion operations with O(log n) complexity.

---

# 📌 CO2 – Graph Traversal Using BFS and DFS

## Objective

To represent veterinary departments and pet services as a graph and analyze connectivity using graph traversal techniques.

## Features

- Graph Representation
- Department Connectivity Analysis
- Breadth First Search (BFS)
- Depth First Search (DFS)
- Efficient Traversal of Veterinary Services

## Data Structure Used

- Graph
- Adjacency Matrix

## Algorithms Used

- Breadth First Search (BFS)
- Depth First Search (DFS)

## Applications

- Veterinary Department Connectivity
- Pet Healthcare Routing
- Service Coordination
- Resource Management Systems

## Outcome

BFS explores departments level by level, while DFS recursively visits all reachable departments to analyze connectivity.

---

# 📌 CO3 – BFS, DFS and Prim's Minimum Spanning Tree

## Objective

To implement graph traversal and network optimization techniques for efficient communication among veterinary departments.

## Features

- Breadth First Search (BFS)
- Depth First Search (DFS)
- Prim's Minimum Spanning Tree (MST)
- Minimum Cost Network Calculation

## Data Structure Used

- Weighted Graph
- Adjacency Matrix

## Algorithms Used

- Breadth First Search (BFS)
- Depth First Search (DFS)
- Prim's Minimum Spanning Tree (MST)

## Applications

- Smart Veterinary Clinics
- Healthcare Resource Planning
- Clinic Communication Networks
- Veterinary Service Optimization

## Outcome

The system efficiently traverses all veterinary departments and determines the minimum-cost network connecting them using Prim's Algorithm.
